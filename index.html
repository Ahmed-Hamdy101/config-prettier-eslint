ESLint & Prettier

Step by Step Configuration Guide

1

Install Node.js

Windows

  • Visit nodejs.org
  • Download LTS Version (Long Term Support)

Mac or Linux

# Mac (Homebrew)
brew update && brew upgrade node

# Linux
sudo apt-get update && upgrade node
2

Initialize NPM Package

Create your project folder and initialize npm:

npm init --yes
# or with yarn
yarn init --yes
3

Prettier Configuration

Install Prettier

yarn add prettier
# or with npm
npm i prettier

Create .prettierrc

# Linux/Mac
touch .prettierrc

# Windows (CMD)
echo "" > .prettierrc

Configuration

{
  "printWidth": 80,
  "tabWidth": 2,
  "useTabs": false,
  "semi": true,
  "singleQuote": true
}

Update package.json scripts

"scripts": {
  "prettier": "prettier --write test \"*.js\" --check"
}
4

Install ESLint with Prettier

Install Dependencies

npm i --save-dev eslint @typescript-eslint/parser typescript \
  eslint-config-prettier \
  eslint-plugin-import \
  eslint-plugin-node \
  eslint-plugin-promise \
  eslint-plugin-react \
  eslint-plugin-jsx-a11y \
  eslint-plugin-standard prettier \
  eslint-config-airbnb-base
5

Create ESLint Configuration

Automatic (Recommended)

npx eslint init
# or if installed globally
eslint --init

Manual Configuration

Create .eslintrc.cjs with this configuration:

module.exports = {
  env: {
    browser: true,
    es2021: true,
  },
  extends: ['airbnb-base', 'prettier'],
  plugins: ['prettier'],
  overrides: [
    {
      env: { node: true },
      files: ['.eslintrc.{js,cjs}'],
      parserOptions: { sourceType: 'script' },
    },
  ],
  parserOptions: {
    ecmaVersion: 'latest',
    sourceType: 'module',
  },
  rules: {
    'prettier/prettier': ['error'],
  },
}
6

Automatic Fixer Scripts

Add to package.json scripts

"scripts": {
  "lint": "eslint . --ext .js",
  "lint:fix": "npm run lint -- --fix",
  "prettier": "prettier --write index.js --check",
  "prettier:fix": "npm run prettier -- --write",
  "format": "npm run prettier:fix && npm run lint:fix"
}
7

Run the Magic!

Execute Format Command

npm run format

Expected Output

> test@1.0.0 format
> npm run prettier:fix && npm run lint:fix

> test@1.0.0 prettier:fix
> npm run prettier -- --write

> test@1.0.0 prettier
> prettier --write test "*.js" --check --write

Checking formatting...
All matched files use Prettier code style!

Ready to Code!

Your project is now configured with ESLint and Prettier
